  - Remediation: Namespace backup slots per primary key, e.g. `_backupKey(primaryKey, index)` returning `${primaryKey}__backup_${index}`. Skip rotation entirely for tiny scalar keys like the active-campaign id, and rotate only when the incoming value actually differs from the stored one.
